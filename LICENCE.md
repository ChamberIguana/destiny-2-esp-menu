## 🧩 About

**Destiny 2 overlay Menu** is a curated list of Destiny 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, loot tracker
- **Quality-of-Life Helpers** — inventory catalog, loadout manager, overlay notes

## ✨ Features

### 🎮 Practice Helpers

## 🛠 Troubleshooting

- **Overlay not showing:** Ensure you run the helper as administrator and that the game is in borderless windowed mode.
- **Game crashes on launch:** Disable any other overlays (Steam, Discord) and try again.
- **Hotkey not working:** Check for conflicts with other software; change `menu_hotkey` in config.
- **Antivirus flags:** Some security tools may flag overlays; add an exclusion for the folder.
